# Allin Stacked

Website for the [Allin Stacked](https://www.youtube.com/@AllinStacked) YouTube channel, served via GitHub Pages at [allinstacked.com](https://allinstacked.com).

## Structure

- `index.html` — single-page site (hero, latest videos, about, socials, contact)
- `assets/css/style.css` — styles
- `assets/js/main.js` — mobile nav + footer year
- `CNAME` — custom domain config for GitHub Pages

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static file server.

## Updating videos

The "Latest Videos" section embeds the channel's uploads playlist automatically — no manual updates needed when you post a new video.
